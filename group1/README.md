# Ecommerce Site

This is a basic e-commerce website built with HTML, CSS, and JavaScript for a group assignment.

## Features

- Product catalog with categories
- Shopping cart with local storage
- Product search and filtering
- Responsive design
- Simulated checkout process
- **Discount coupons** (SAVE10, SAVE20, FREESHIP)
- **Customer reviews and ratings** on product pages

## Pages

- Home: Featured products
- Shop: Browse all products with filters
- Product Detail: Individual product view with reviews
- About: Information about the site
- Contact: Contact form
- Cart: View and manage cart items
- Checkout: Simulate purchase with coupon support

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Setup

1. Clone or download the repository
2. Open index.html in a web browser
3. For hosting, upload to a free host like 000webhost or GitHub Pages
